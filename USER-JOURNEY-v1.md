# PrimeDesk User Journey v1 — What Makes It Successful

**Who:** Amaka, 28, owns Glow Studio (beauty, 3 staff, Lagos). Takes bookings on WhatsApp + transfers to Moniepoint, tracks in notebook. 25 chats/day, misses 3-4.

## Journey Steps + Success Signs

### Step 1: Business Setup (Goal: 1 min, no confusion)
Sees: "Tell us about your business" + 4 simple picks.
Does: Types name, picks Beauty, picks "I use a few tools", picks 3-10.
Feels: "Easy, they know people like me."
Success: 95% finish. Fail if: too many fields. Fix: keep 4 only.
Needs: Big dropdowns, example placeholder, Continue button.

### Step 2: Pick Process (Goal: focus on one pain)
Sees: 3 cards Booking / Orders+Payment / Follow-up.
Does: Taps Booking (waitlist pain).
Feels: "They won't force whole business at once."
Success: 90% pick one. Needs: 1-line desc each + "Mine is different" link.

### Step 3: Describe Work (Goal: truth in own words)
Sees: One big box + example in WhatsApp language.
Does: Types or voice-note style: "Clients DM, I send price, they transfer, I book in notebook..."
Feels: Heard, not tested.
Success: 80% write 20+ words. Needs: example shown, Build My Process button.

### Step 4: Process Map (Goal: MAGIC MOMENT)
Sees: Boxes ↓: Enquiry > Quote > Payment > Booking > Staff > Service > Follow-up.
Does: Renames "Booking" to "Book time", deletes duplicate, Adds "Deposit check".
Clicks: Confirm — This is my process.
Feels: "Yes! This is my business!"
Success: 70% confirm without help. This is #1 MVP metric. Needs: editable list, Add row, Back link.

### Step 5: Plan (Goal: trust advice, not oversell)
Sees: "You don't need everything at once" + Level ORGANIZE + Why 1 sentence + 3 cards Start/Next/Later each with Why + When to upgrade + checkbox.
Does: Ticks "I use WhatsApp, notebook, Moniepoint", marks Scheduling as Later.
Feels: Relief — "They didn't sell me CRM I can't handle."
Success: 50% accept Start Now (2-4 tools). Needs: Why line per tool, max 4 items in Start Now.

### Step 6: Home - 3 Tabs (Goal: return)
Tab 1 My Process: map + taps Follow-up to Stuck.
Tab 2 My Tools: WhatsApp-In use, Notebook-In use, Moniepoint-In use, Scheduling-Add later. Each shows When to upgrade.
Tab 3 Growth Path: Today ✓ WhatsApp+List+Payment → Next List+Scheduling when >30/wk → Future CRM when follow-up hard.
Feels: Control + clear next step.
Success: 30% return in 7 days to check Growth Path. Needs: manual Done/Waiting/Stuck toggle, no tech errors.

## What Must Be Ready Behind Each Step (so journey doesn't break)
- Templates JSON for 3 processes (stages + needs).
- Level rule: manual→Start, few tools→Organize, many→Connect.
- Plan rules: Start max 4 tools, each with Why + When.
- Save: browser save first, account save second (so network drop doesn't lose work).
- Tracking: log finished Step 1,2,3,4,5,6 + time. No personal chat content stored.

## Failure Watchlist
- Drop at Step 3 → example not relatable. Fix wording to Nigeria example.
- Drop at Step 4 → map wrong. Allow quick edit, add missing stage.
- No accept at Step 5 → too many tools suggested. Cut to 2-4.
- No return → Growth Path vague. Make Next trigger concrete ("when >30 chats/week").

## Your Test Script (5 owners)
1. Watch them do 1-6 silently, time it.
2. Ask: "Is map correct? What would you change?"
3. Ask: "Is Start Now correct? What would you remove?"
4. Ask: "Would you pay / refer for this clarity?"
Pass if 4/5 say yes to map + 3/5 to plan.

---
If journey passes, we build Phase 3 one live link. If not, we fix words/templates, not add features.

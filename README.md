# PrimeDesk — Business Driver / Business Uber

> **PrimeDesk Promise:** You don't need to figure out all the technology. Tell PrimeDesk how your business works, and we'll help you build the right digital system for where you are today — and where you're going next.

PrimeDesk takes a business to its destination with the right driver (digital tools).
It understands **business process first**, before suggesting technology, automation, or optimization.

Like Uber: Customer need → Right driver → Journey → Status.
Like PrimeDesk: Business need → Right technology → Business process → Status → Improvement.

**Philosophy:** Start where the business is. Build toward where it needs to go.

## MVP in 30 seconds

1. Owner tells us about business (1 min)
2. Picks 1 process from 3 templates: Booking / Orders+Payment / Follow-up
3. Describes work in own words
4. Confirms process map: "Yes, this is my business"
5. Gets plan: Start Now (2-4 tools) / Next / Later + why
6. Sees Home with Growth Path: Today → Next → Future

MVP wins if owners finish in <10 mins, say the map is correct, accept the Start Now plan, and return in 7 days.
